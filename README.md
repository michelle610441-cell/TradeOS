# TradeOS V3.1

TradeOS 是一个面向 A 股短线交易的个人复盘与执行辅助工具，用固定流程整理盘面判断、交易计划、账户持仓和盘后复盘。

## V3.1 更新

- 重排交易日首页，修复 iPad 上输入框挤压、重叠的问题
- 持仓详情不再显示“交易所”输入项，旧数据仍兼容
- 新增 `N字形走势`、`楔形/三角形` 两种交易模式
- 新增右下角“纪律雷达”和每日格言
- 量能小于 1 时提示“量能不足，谨慎追高”
- 提醒仅作提示，不阻止保存和记录交易

## 使用方法

1. 把仓库根目录的 `index.html` 替换为本版本文件。
2. 在 GitHub Pages 部署完成后，确认页面右上角显示 `V3.1 · 纪律雷达版`。
3. 软件会继续读取 V3.0.1 等旧版本保存在同一网址、同一浏览器中的数据。

日常运行只需要 `index.html`。`app.js` 和 `build.cjs` 用于后续开发维护。

## 数据与隐私

交易数据保存在浏览器本地存储中。公开仓库不应提交完整备份、AI 分析 JSON、账户截图或个人交易资料；`.gitignore` 已默认忽略 JSON 文件。

## 说明

TradeOS 不接入实时行情，也不自动下单。软件中的规则、统计和提醒不构成投资建议。
