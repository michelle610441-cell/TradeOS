# TradeOS V2.6 Complete

完整保留 V2.5 的交易链：
交易日 → ①宏观 → ②大盘 → ③大势 → ④情绪 → ⑤板块 → ⑥个股 → ⑦买点 → ⑧仓位 → ⑨持仓 → ⑩卖出 → ⑪复盘/博主 → ⑫统计 → ⑬龙虎榜。

特点：
- iPad 优先的蓝紫科技渐变 UI
- 全本地 localStorage，不接外部行情/API
- 多股票独立买点/仓位
- 持仓、卖出、交易模式统计、博主记录
- 龙虎榜机构/游资手动复盘
- JSON 导入兼容旧版 days/bloggers，以及此前 current/archive 格式
- JSON 导出继续采用 days/bloggers 主结构，便于长期兼容
