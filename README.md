# TradeOS

TradeOS 是一个面向 A 股短线交易的个人复盘与执行辅助工具，帮助用户按照固定流程记录交易判断、制定计划并复盘执行情况。

## 主要功能

- 按“宏观—大盘—大势—情绪—板块—个股”整理盘面判断
- 记录买点、仓位、持仓、卖出和每日复盘
- 管理账户流水、持仓计划与交易统计
- 记录龙虎榜、机构、游资及关注博主观点
- 导出完整备份或供 AI 分析使用的决策 JSON
- 支持电脑与 iPad 浏览器使用

## 使用方法

1. 直接打开 `index.html`；或把仓库部署到 GitHub Pages。
2. 数据只保存在当前浏览器的本地存储中，不会上传到服务器。
3. 更换设备、浏览器或网页地址前，请先在软件中导出完整备份。

## GitHub Pages

进入仓库的 **Settings → Pages**，选择从默认分支根目录部署。等待发布完成后，打开 GitHub 提供的网址即可。

## 项目文件

- `index.html`：可直接运行的完整单文件版本
- `app.js`：主要程序源码
- `build.cjs`：将源码嵌入 `index.html` 的构建脚本
- `AI_SCHEMA.md`：AI 分析 JSON 字段说明

## 数据与隐私

公开仓库不包含任何用户交易记录。请勿把导出的 JSON 备份、账户截图或其他个人交易资料提交到公开仓库。

## 说明

TradeOS 是复盘和纪律辅助工具，不接入实时行情，也不自动下单。软件中的规则、统计和提醒不构成投资建议。
