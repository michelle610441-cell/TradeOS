# TradeOS V2.7 · 账户系统

在 V2.6.1 完整交易链基础上新增：

- 持仓跨交易日延续：新建交易日后自动继承上一交易日未清仓持仓
- 每日只需更新收盘价
- 账户基础：初始本金、现金、追加资金、取出资金
- 自动计算：持仓市值、浮动盈亏、总权益、总盈亏、累计收益率、当前仓位
- 交易流水：买入、加仓、减仓、清仓
- 自动更新平均成本、现金、持仓数量、已实现盈亏
- 每日账户快照
- 统计中心新增账户权益曲线
- 统计中心新增仓位加权收益、累计成交金额、已实现盈亏
- SOP纪律对比
- 继续保留原有 ①～⑬ 完整流程、龙虎榜、JSON 兼容导入、统计可编辑/删除

说明：
- 入金/出金不会被当作投资收益
- 第一版手续费字段为可选
- 当前采用本地 localStorage，不连接外部行情/API
